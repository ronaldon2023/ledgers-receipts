The receipt

When it starts
The moment the order is submitted, from that response. Then updated at each step.
What it holds
Check results, never check logic. Each check shows what it compared and its evidence.
Rerun
It records which checks version and policy ran, so anyone can rerun them.
One AI step not on the board
AI pulls out what Claude says it did. Code compares that with the database. The AI never decides the verdict.

Onboarding

The owner opens Claude Code and installs in 3 steps.

  1. Add Anthropic's marketplaceknowledge-work-plugins
  2. Add our marketplacethe-ledgers
  3. Install our pluginledgers-receipts

Comes with Small Business. Installing ours also installs the Claude for Small Business plugin as a dependency.

Two onboardings, in order. The Small Business plugin's onboarding (smb-onboard) runs, then ours, which skips anything theirs already asked. A session-start hook starts ours when no policy exists yet.

Answers become the policy. The owner answers a few questions: payment threshold, monthly budget, bank account floor, approved suppliers, and which tools and outside systems they use. Onboarding writes the answers to the policy JSON file.

How the website and backend talk

They never call each other directly. The backend rewrites one JSON file after every step, and the website reads that file to show the run live.
